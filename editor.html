This editor only prepares a file on your device. It does not save to GitHub or publish. Download your work before leaving; unsaved changes are lost.

1. Load the latest archive. 2. Select or add a record. 3. Apply edits to this session. 4. Download the complete JSON file. 5. Upload it on a GitHub branch and request review.

Media files must be uploaded separately under assets/. Keep archival originals in the Society's separate backed-up storage. Rights and credits are required for web copies. Open GitHub to request review.
