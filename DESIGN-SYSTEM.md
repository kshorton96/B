# Traditional historical atlas

The guiding reference is a typeset county gazetteer: paper, ink, generous margins and fine rules. No invented seals, artifacts, dates or textures.

## Foundations

- Forest ink `#27352F`: text, primary controls and focus context.
- Aged paper `#F3ECDD`: page; warm white `#FFFCF5`: reading surfaces.
- Antique brass `#A18858`: decorative rules only; dark brass `#716039`: readable supporting labels.
- Leather `#8A4D32`: links and evidence notices. Olive `#72775A`: map accents.
- Georgia/system book serifs: masthead, headings and narratives. System sans serif: controls, evidence and navigation. Monospace: archival reference.
- Body 18px / 1.6; captions 16px; controls at least 44px high. Narrative measure 70 characters.
- Spacing: 4, 8, 12, 16, 24, 32, 48px. Thin borders, square corners, no decorative shadows.

## Composition

Centered two-line masthead, small Society attribution and four primary destinations. Search remains visible; native disclosure contains the existing multi-select categories and advanced controls. Desktop map and index share a spread. Mobile map precedes the index. No categories or record IDs are migrated.

Record reader is a nonmodal, fixed side panel on desktop and a full-width reading panel on phones. It retains map context, receives keyboard focus, closes with Escape and returns focus to the selected index entry. Evidence notice precedes narrative; media and captions retain original colors; technical catalog details sit in a disclosure. References remain in the article. Records without media need no placeholder. Stable IDs are displayed verbatim as archival references.

## Interaction and accessibility

Underlined links, explicit labels, visible focus, native details/summary controls and generous touch targets. Text reflows at narrow widths and 200% zoom. No animations. Search/filter changes update count and active filter summary. Future authenticated layers belong in the map-heading control area; do not show a nonfunctional layer selector or invent overlays.

## Stewardship

Public empty state invites contributions and explicitly labels the demonstration collection. Existing noindex restriction, records, submission configuration and editor workflows remain unchanged. Volunteer tools use the same palette with practical sans-serif forms.
